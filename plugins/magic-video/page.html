统一入口：tumeiapi.com

准备具备模型权限和可用额度的本站API Key。先查看支持模型清单，再复制对应的调用示例。模型选择、创建、查询、下载均使用本站接口。

1. 地址与鉴权

Base URLhttps://tumeiapi.com
鉴权Authorization: Bearer YOUR_TUMEIAPI_KEY
创建视频POST /v1/videos
查询任务GET /v1/videos/{id}
下载成片GET /v1/videos/{id}/content，需要鉴权
export FASTAIAPI_KEY='替换为你的本站API Key'
curl --fail-with-body 'https://tumeiapi.com/v1/models' \
  -H "Authorization: Bearer $FASTAIAPI_KEY"

返回结果按当前令牌权限过滤；清单不保证每个分组同时开放全部型号。模型可用性和价格以模型广场及最终账单为准。

3. 请求字段与素材类型

标准请求

用于mx-h3、sd-*及w3-p-c1。

字段类型必填说明
modelstring是模型ID，完整填写。
input.promptstring是文字描述，可用“图1”“音频1”“视频1”指代有序素材。
input.mediaarray否参考素材列表；文生可省略。
input.media[].typestring素材项必填使用下表列出的媒体类型。
input.media[].urlstring素材项必填公网HTTP(S)直链，不接受本地文件路径。
parameters.durationinteger是输出秒数，范围按型号表。
parameters.resolutionstring建议如720p，按型号选择。
parameters.ratiostring建议如16:9；mx-h3仅支持9:16。
媒体类型含义
first_frame首帧图片，控制起始画面。
last_frame尾帧图片，控制结束画面；与首帧配合使用。
reference_image人物、场景、道具、风格或拼图参考，提示词中可按“图1、图2”指代。
reference_voice声音参考，提示词可使用“音频1”。
reference_video动作、表情和镜头节奏参考，提示词可使用“视频1”。

图片建议至少300×300。首帧、尾帧和参考图合计计入图片上限；首帧与尾帧各最多一张。参考素材按数组顺序编号。支持音视频参考的型号才能传入相应素材。

兼容请求

用于minimax-h3*、wan2.*、ltx-2.3*。选择模型即可，服务自动处理接入。

字段类型说明
model / promptstring完整模型ID与提示词，必填。
secondsinteger输出时长，按型号范围。
sizestring宽x高，如864x480；Wan2.2按长边档位提供，不同时传固定尺寸。
input_referencestring / file首帧URL，或multipart上传的首帧文件。
metadata.last_frame_urlstring尾帧URL，仅支持尾帧的型号使用。
metadata.reference_imagesstring[]有序人物、场景、风格参考图。
metadata.reference_audiosstring[]参考音频；数字人要求一段足够长的完整配音。
metadata.reference_videosstring[]参考视频，仅H3 X支持此项。
metadata.fpsinteger按型号选择帧率，固定帧率不可任意修改。

H3常用尺寸864×480、1376×768、1920×1088，竖屏交换宽高。LTX X宽高按64对齐；其他H3/LTX按32对齐。Wan2.2长边档位为480、768、1024、1280、1536，实际输出按原图比例对齐。只传一种尺寸描述，相同参数冲突会被拒绝。

5. 查询任务与下载

创建成功后保存响应中的id。排队期间每20秒或更长时间查询一次，不重复提交创建请求。

{"id":"task_example","object":"video","model":"sd-2-c4","status":"queued","progress":0}
TASK_ID='替换为创建接口返回的任务ID'
curl --fail-with-body "https://tumeiapi.com/v1/videos/$TASK_ID" \
  -H "Authorization: Bearer $FASTAIAPI_KEY"
status处理方式
queued排队中，继续查询原任务。
in_progress生成中，可参考progress和stage。
completed已完成，通过内容接口下载。
failed读取错误信息后停止轮询，确认原因再重新创建。
{"id":"task_example","model":"sd-2-c4","status":"completed","video_url":"/v1/videos/task_example/content","seconds":5}
curl --fail --location --proto '=https' --proto-redir '=https' \
  "https://tumeiapi.com/v1/videos/$TASK_ID/content" \
  -H "Authorization: Bearer $FASTAIAPI_KEY" --output output.mp4

内容接口需要当前用户的有效Key，不是免鉴权直链。结果请及时保存；不同型号的结果保存期限不同。创建超时或断网后先检查原任务记录，已经取得任务ID时继续查询原任务。

字字动画安装

  1. 解压ZIP，将整个video_plugin_fastai_magic文件夹放入_internal/plugins/video_plugins/。
  2. 重启客户端，选择“FastAiApi 视频”，填写本站Key并测试连接。
  3. 选择具备权限的模型、生成方式、时长及画幅；支持的素材由模型决定。

单个本地素材最多10MB；超大素材使用公网URL。插件保留任务ID，断网或等待超时后可继续查询原任务。可选资源池Key用于已经授权的自有资源，不需要向插件提供云账号凭据。

new-api安装

  1. 标准视频包：打开installer.html，将安装按钮拖到书签栏；在自己的面板登录管理员，再运行书签填写本站Key。
  2. 兼容视频包：导入plugin-upload.json，激活1.9.7；参考downstream-channel-template.json设置本站地址与Key，按自己的业务配置价格。
  3. 安装要求面板支持Task Plugin API v1。升级保留任务和自定义价格，不把用户API Key写到公开页面。

8. 常见问题

  • 401/403：检查本站Key、期限、模型权限及可用额度。
  • 400/422：检查该型号的时长、分辨率、画幅及参考素材数量；错误参数不会变成有效生成任务。
  • 没有音轨：Wan2.1/2.2没有音轨；其他型号是否支持参考音频以表格为准。
  • 首尾帧没生效：首帧、尾帧与普通参考图需要分别提供，且必须选支持对应方式的模型。
  • 等待较久：排队或生成时继续查询原ID；进度不是准确剩余时间。
  • 创建超时：先核对控制台记录，勿立即重发付费请求。
  • 视频下载失败：使用本站内容接口并携带有效Key，完成后及时保存。
