1. 站点与鉴权

fastaiapi.cloud 与 newapi.fastaiapi.cloud 均支持本文两个模型。两站使用相同的 Images 接口路径、参数和请求体；只需更换 Base URL 与对应站点的 API Key。

站点Base URL可用分组
FastAiApihttps://fastaiapi.cloudgpt-pro、gpt-Image-超分
New APIhttps://newapi.fastaiapi.clouddefault、企业VIP、Image2.6两分

鉴权请求头为 Authorization: Bearer YOUR_API_KEY。请在所选站点创建 Key 并选择对应分组；两个站点的 Key 分别管理。

# 选择一个站点，末尾不加 /v1
export BASE_URL='https://fastaiapi.cloud'
# 使用 New API 时改为：https://newapi.fastaiapi.cloud
export API_KEY='YOUR_API_KEY'

2. 模型说明与价格

GPT Image 2.6 Flare

gpt-image-2.6-flare：面向快速创作与反复迭代，适合批量素材、电商配图和海报草稿。支持文字生图、参考图编辑、GIF 动图与SVG 矢量图，结果以文件 URL 返回。

GPT Image 2.6 Sunburst

gpt-image-2.6-sunburst：面向精细画面与设计创作，适合产品视觉、海报设计和精细修图。支持文字生图、参考图编辑、GIF 动图与SVG 矢量图，结果以文件 URL 返回。

3. 通用参数

文字生图使用 POST /v1/images/generations，图片编辑使用 POST /v1/images/edits，JSON 请求头为 Content-Type: application/json。

参数说明
model必填：gpt-image-2.6-flare 或 gpt-image-2.6-sunburst。
prompt必填，描述画面或编辑要求。
n生成次数，1–4，默认 1。一次生成可能返回多份图片文件，见返回说明。
output_formatpng、jpeg（jpg）、webp、gif、svg。GIF / SVG 使用限制见下节。
response_format建议 url。当前非流式接口返回 data[].url；传 b64_json 也以 URL 返回。
aspect_ratio宽高比，如 1:1、16:9、9:16。兼容 aspectRatio。
image_size分辨率提示：1K、2K、4K；兼容 resolution、imageSize，按此顺序取第一个有效字段。
size兼容像素尺寸（如 1024x1024）、比例或分辨率档位，也接受 auto、default。明确像素尺寸优先；这两个模型不保证严格输出对应像素数。
qualityauto、low、medium、high、xhigh、max、standard、hd。画质提示，不保证每档产生固定效果。
background兼容背景提示字段，不保证透明背景效果。
stream本文示例均为 false；GIF、SVG 必须为 false 或省略。
frame_countGIF 可选帧数提示；不补默认值，不保证精确遵循。
frame_duration_msGIF 可选单帧时长提示，单位毫秒；不补默认值，不保证精确遵循。
images编辑时使用 [{"image_url":"公开图片 URL 或 Data URL"}]。此结构两站通用。

尺寸字段是构图与分辨率提示，实际输出尺寸可能不同。GIF、SVG 保留原文件，不做本地像素缩放。

4. 文字生图

先设置上文的 BASE_URL 与 API_KEY，以下请求在两站完全相同。切换另一个模型时只修改 model。

curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.6-flare",
    "prompt": "一只小猫坐在窗边，温暖的午后光线",
    "n": 1,
    "aspect_ratio": "1:1",
    "image_size": "1K",
    "output_format": "png",
    "response_format": "url",
    "stream": false
  }'

5. GIF 与 SVG

GIF 动图

两个模型均支持请求 GIF 动图。可用于文字生成与参考图编辑，结果上传文件存储后返回可下载的 URL；不支持流式请求。

curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.6-flare",
    "prompt": "生成循环 GIF 动图：蓝色小球在白色背景上轻轻弹跳",
    "output_format": "gif",
    "frame_count": 20,
    "frame_duration_ms": 100,
    "response_format": "url",
    "stream": false
  }'

SVG 矢量图

两个模型均支持请求 SVG 矢量图。SVG 仅支持无参考图的文字生成，不支持图片编辑、参考图输入或流式请求。

curl "$BASE_URL/v1/images/generations" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.6-sunburst",
    "prompt": "生成真正的 SVG 矢量文件：白色背景中央一个蓝色圆形图标，使用圆形路径，不要栅格图",
    "output_format": "svg",
    "response_format": "url",
    "stream": false
  }'
以实际文件格式为准。

GIF、SVG 是生成格式请求，可能返回 PNG 等栅格结果。接口会保留实际字节、后缀与 MIME，不会把 PNG 改名为 GIF 或 SVG；需要指定格式的应用应检查下载文件。GIF 一次生成也可能同时包含动图和 PNG 预览，程序应遍历 data[]。

6. 图片编辑

两站均使用 images 数组传入参考图。image_url 可填写可公开下载的 HTTP(S) URL，或 data:image/png;base64,...。服务会实际读取参考图并执行生成。

curl "$BASE_URL/v1/images/edits" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.6-sunburst",
    "prompt": "保留主体，把背景改为柔和的浅蓝色",
    "images": [{"image_url": "https://example.com/reference.png"}],
    "n": 1,
    "output_format": "png",
    "response_format": "url",
    "stream": false
  }'

也可以请求 output_format: "gif" 将参考画面制作成动图。单张参考图不超过 50 MiB，最多 16 张，累计不超过 100 MiB；图片地址须可被服务访问。

7. URL 与返回结果

{
  "created": 1793910000,
  "data": [
    {
      "url": "https://YOUR_FILE_HOST/generated-image.gif",
      "revised_prompt": "你的原始提示词"
    }
  ]
}

data[].url 是图片或动图的下载地址。GIF、SVG 与普通图片一样存储为文件，并通过 URL 访问；链接保留时间以站点存储策略为准，需要长期使用时请及时保存。

n=1 执行一次生成，可能保留多份返回文件；n>1 执行多次生成，最终最多返回 n 份。GIF 帧数、画质与尺寸是生成提示，业务端应检查实际结果。

遇到 401 时检查所选站点的 API Key；模型不可用时检查 Key 分组及模型名称；429 或临时服务繁忙时使用适当退避，避免对已成功返回的请求重复提交。
