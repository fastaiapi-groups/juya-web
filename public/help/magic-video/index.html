3. 请求字段与参考素材

POST /v1/videos
Content-Type: application/json
Authorization: Bearer YOUR_FASTAIAPI_KEY
字段类型说明
modelstring完整模型 ID，必填，区分大小写。
input.promptstring非空提示词，必填；可用“图1”“视频1”“音频1”等指代素材。
input.mediaarray可选参考素材列表，数量须满足所选模型限制。
input.media[].typestringfirst_frame 首帧、last_frame 尾帧、reference_image 参考图、reference_voice 参考音频、reference_video 参考视频。
input.media[].urlstring素材的公网 HTTP(S) 直链；API 请求不接受本地文件路径。
parameters.durationinteger输出秒数，必填，范围见上表。
parameters.resolutionstring建议明确填写，必须为该模型支持的分辨率。
parameters.ratiostring建议明确填写；多数型号支持多种比例，mx-h3 仅 9:16，sd-2-c4 为 1:1 / 16:9 / 9:16。

本接口只接受 JSON。也支持顶层 prompt、duration / seconds、resolution、ratio / aspect_ratio，以及 images、audios、videos 数组。相同计费参数在顶层和 parameters 中冲突时会被拒绝；不要放入 metadata。一次任务仅生成一条视频。

3.1 文生视频

curl --fail-with-body 'https://tumeiapi.com/v1/videos' \
  -H "Authorization: Bearer $FASTAIAPI_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "sd-2-c1",
    "input": {"prompt": "清晨的湖面，一只白色纸船缓缓漂过，镜头平稳"},
    "parameters": {"duration": 4, "resolution": "720p", "ratio": "16:9"}
  }'

3.2 首尾帧与多模态参考

{
  "model": "sd-2-c4",
  "input": {
    "prompt": "首帧中的人物向前走，最后到达尾帧的花园场景",
    "media": [
      {"type": "first_frame", "url": "https://your-cdn.example/first.png"},
      {"type": "last_frame", "url": "https://your-cdn.example/last.png"}
    ]
  },
  "parameters": {"duration": 4, "resolution": "720p", "ratio": "16:9"}
}

参考生视频请将媒体类型改为 reference_image、reference_voice 或 reference_video；参考图不会自动改成首帧。图片建议至少 300×300；SD 2.0 参考视频场景需注意输入与输出时长合计限制，通常不超过 25 秒。不同系列的数量和时长能力不通用，以所选模型为准。

4. 查询任务与下载视频

创建成功后保存响应中的 id（兼容 task_id）。每次查询间隔至少 20 秒，排队时不要重复提交新任务。

TASK_ID='替换为任务 ID'
curl --fail-with-body "https://tumeiapi.com/v1/videos/$TASK_ID" \
  -H "Authorization: Bearer $FASTAIAPI_KEY"
状态处理
queued排队中，继续查询。
in_progress生成中，继续查询。
completed可以下载成片。
failed读取错误信息，保留任务 ID 后停止轮询。
{
  "id": "task_example",
  "object": "video",
  "model": "sd-2-c1",
  "status": "completed",
  "seconds": "4",
  "video_url": "/v1/videos/task_example/content",
  "url": "/v1/videos/task_example/content"
}

本站返回自己的内容接口路径。完整下载 URL 为 https://tumeiapi.com/v1/videos/{id}/content，仍需携带有权访问任务的本站 Key，不能当作免鉴权公开直链。

DOWNLOAD_URL="https://tumeiapi.com/v1/videos/$TASK_ID/content"
printf '视频下载 URL：%s\n' "$DOWNLOAD_URL"
curl --fail --location --proto '=https' --proto-redir '=https' \
  "$DOWNLOAD_URL" -H "Authorization: Bearer $FASTAIAPI_KEY" \
  --output output.mp4

不要添加 --location-trusted。结果有有效期，尤其 w3-p-c1 的模型说明为 3–5 小时，请完成后尽快下载。

5.1 字字动画：安装后只填写 Key

  1. 解压 ZIP，将整个 video_plugin_fastai_magic 文件夹放入 _internal/plugins/video_plugins/。
  2. 重启字字动画，在视频插件列表选择“FastAiApi 视频”。
  3. 填写 tumeiapi.com 的 API Key，点击“测试连接”。模型按当前 Key 权限显示；魔法模型使用魔法视频分组，GPU 模型使用具备该模型权限的分组。接口地址已固定，无需填写。
  4. 选择模型与生成方式。插件自动限制模型的分辨率和时长，本地素材自动上传，单个文件不超过 10MB；较大素材可使用公网 URL。

插件会保存任务 ID，超时或断网后重新运行会继续查询原任务；不会自动重复创建付费请求。若创建响应不确定，请先核对控制台任务记录。视频成功后会自动下载，并在日志打印完整的本站下载 URL。

5.2 new-api：一键完成渠道和定价

  1. 解压接入包，在浏览器打开包内 installer.html，把“安装魔法视频”按钮拖到书签栏。
  2. 打开你自己的 new-api 后台，正常登录超级管理员；通过面板原有的安全验证。
  3. 点击安装书签，输入本站“魔法视频分组”Key，点击“安装并启用”。无需手工填写 Base URL、模型列表、分辨率或价格。
  4. 安装完成后，可使用你自己面板的 Key，调用自己面板的 /v1/videos。

安装器适用于提供 Task Plugin API v1 和模型计费配置接口的 new-api。旧版本会先提示不兼容；不会把普通渠道当成已安装的视频插件。安装会保留已有自定义定价，新增价格按本地面板配置的计价单位换算；本地已有分组倍率继续生效。

已有安装器书签可直接运行。也可以把下面的入口拖到书签栏，再在自己的后台使用：

安装魔法视频 → 拖到书签栏

安装器只向当前面板调用管理 API，不导出管理员会话。配置未完成时，新建渠道保持停用，可修复问题后重新运行。源码 plugin.js、模型清单和安装脚本均包含在 ZIP 内，便于审阅。

6. 完整 cURL 示例

依赖 Bash、curl、jq。下载 demo.sh，在独立目录执行 FASTAIAPI_KEY='你的本站Key' bash demo.sh。它只创建一次任务，随后查询并打印完整下载 URL、保存视频。创建超时先查控制台，避免重复付费。

展开完整脚本
#!/usr/bin/env bash
set -euo pipefail
: "${FASTAIAPI_KEY:?请设置 tumeiapi.com 魔法视频分组的 FASTAIAPI_KEY}"
command -v curl >/dev/null
command -v jq >/dev/null
BASE_URL='https://tumeiapi.com'
if [ -z "${TASK_ID:-}" ]; then
  if [ ! -e magic-video-create.json ]; then
    : > magic-video-create.json
    curl --fail-with-body --silent --show-error --connect-timeout 10 --max-time 120 \
      "$BASE_URL/v1/videos" \
      -H "Authorization: Bearer $FASTAIAPI_KEY" -H 'Content-Type: application/json' \
      -d '{"model":"sd-2-c1","input":{"prompt":"清晨的湖面，一只白色纸船缓缓漂过，镜头平稳"},"parameters":{"duration":4,"resolution":"720p","ratio":"16:9"}}' \
      --output magic-video-create.json
  fi
  TASK_ID=$(jq -er '.id // .task_id | select(type=="string" and length>0)' magic-video-create.json) || {
    echo '未取得任务 ID；请先核对控制台任务，勿自动重复提交。' >&2; exit 1;
  }
fi
printf '任务 ID：%s\n' "$TASK_ID"
deadline=$((SECONDS+7200))
while [ "$SECONDS" -lt "$deadline" ]; do
  curl --fail-with-body --silent --show-error --connect-timeout 10 --max-time 60 \
    "$BASE_URL/v1/videos/$TASK_ID" -H "Authorization: Bearer $FASTAIAPI_KEY" \
    --output magic-video-task.json
  status=$(jq -er '.status' magic-video-task.json)
  printf '状态：%s\n' "$status"
  case "$status" in
    completed)
      DOWNLOAD_URL="$BASE_URL/v1/videos/$TASK_ID/content"
      printf '视频下载 URL：%s\n' "$DOWNLOAD_URL"
      curl --fail --silent --show-error --location --proto '=https' --proto-redir '=https' \
        --connect-timeout 10 --max-time 180 "$DOWNLOAD_URL" \
        -H "Authorization: Bearer $FASTAIAPI_KEY" --output output.mp4.part
      mv output.mp4.part output.mp4
      echo '视频已保存：output.mp4'; exit 0;;
    failed)
      jq '{id,status,error}' magic-video-task.json >&2; exit 1;;
    queued|in_progress) sleep 20;;
    *) echo '无法识别任务状态，请保留响应和任务 ID 联系支持。' >&2; exit 1;;
  esac
done
printf '等待超时；指定 TASK_ID=%s 可继续查询，勿重复创建。\n' "$TASK_ID" >&2
exit 124

7. 常见问题

  • 401 / 403：核对 Key 是否来自 tumeiapi.com、账户额度、令牌期限及模型 / 分组权限。本站 Key 与其他站点不通用。
  • 400：检查模型支持的时长、分辨率、参考素材数量及画幅比例，修改后再提交。
  • 排队很久：保存任务 ID，继续查询。进度和平均耗时不保证下一条任务的完成时间。
  • 创建超时：先看控制台任务记录，不自动重发。已经拿到 ID 时应继续原任务。
  • 视频无法下载：带上本站 Key，使用完整的本站内容 URL；尽快保存，避免链接过期。
  • new-api 安装中断：保留安装器错误信息，检查版本和管理员权限，修复后再运行；不要手工开启尚未完成定价的渠道。
