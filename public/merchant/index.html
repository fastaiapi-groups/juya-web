PUBLIC VERIFICATION API

让你的应用连接卡密服务

以下接口无需后台登录或管理员 Token。卡密和授权凭证请通过 HTTPS 发送。

POST/api/cards/check

检查卡密

只传卡密即可查询状态，不激活、不绑定设备、不占用名额。

{ "code": "YOUR_CARD_CODE" }
POST/api/activate

激活设备

首次使用时绑定稳定设备标识，获取 License Token。

{ "code": "YOUR_CARD_CODE",
  "deviceId": "installation-id" }
POST/api/verify

验证授权

传入激活返回的授权凭证，检查卡密和设备绑定是否仍有效。

{ "license": "YOUR_LICENSE_TOKEN" }
