卡密公开验证接口

使用当前站点域名作为基础地址。以下三个接口无需商户登录、Cookie 或 Authorization 请求头，支持跨域 POST。请求须使用 Content-Type: application/json。

本项目生成的卡密在本项目验证。旧 xiaoxiao 后台的卡密及 License Token 不会自动导入，也不能直接在这里验证。

1. 检查卡密，不激活、不绑定设备

POST /api/cards/check
{ "code": "YOUR_CARD_CODE" }

成功响应：

{
  "ok": true,
  "reason": "",
  "code": "YOUR_CARD_CODE",
  "product": "漫剧 VIP",
  "expiresAt": null,
  "maxUses": 1,
  "usedDevices": 0,
  "canActivate": true
}

ok 表示卡密本身有效；canActivate 表示还有新设备名额。已达上限的有效卡密仍可供已绑定设备使用。检查不会创建授权凭证、绑定设备或改变销售状态。

无效卡密：{ "ok": false, "reason": "该卡密已过期" }。接口不会返回商户、代理、登录账号、备注等后台信息。

2. 激活卡密并绑定设备

POST /api/activate
{ "code": "YOUR_CARD_CODE", "deviceId": "client-installation-id" }

code 自动去除首尾空白并转为大写。deviceId 必须由客户端生成并持久保存，最长 200 字符；兼容 device_fingerprint 字段，非空 deviceId 优先。

{
  "code": 0,
  "message": "ok",
  "data": {
    "access_token": "YOUR_LICENSE_TOKEN",
    "token": "YOUR_LICENSE_TOKEN",
    "refresh_token": "YOUR_LICENSE_TOKEN",
    "expires_in": 0,
    "user": { "username": "card-example", "email": "" }
  }
}
  • 以 code === 0 判断业务成功。失败返回 { "code": 1, "message": "失败原因" }。
  • 同一设备重复激活同一卡密不会增加设备数。同一商户的同一产品，每台设备最多绑定2张当前有效卡；过期、停用、删除或解绑后不占次数。每张卡的设备数量上限独立生效，超限返回“同一产品在本机最多可绑定2张有效卡密”。
  • 三个 Token 字段均为同一份 License Token；没有单独的刷新接口，也没有在此创建账号会话。
  • expires_in 单位为秒，永久卡为 0。限时卡从生成时开始计时，激活不延长有效期。

3. 校验已激活的授权凭证

POST /api/verify
{ "license": "YOUR_LICENSE_TOKEN" }

license 必须是激活响应中的 data.access_token 或 data.token，不能直接传卡密字符串。License Token 不是标准 JWT；客户端以服务器返回结果为准。

{
  "ok": true,
  "reason": "",
  "expiresAt": null,
  "code": "YOUR_CARD_CODE"
}

以 ok === true 判断有效。expiresAt 为 Unix 毫秒时间戳，null 表示永久。失败示例：{ "ok": false, "reason": "授权凭证无效" }。

卡密被禁用、过期或删除，或所属商户被停用后，检查、激活和授权校验均立即拒绝；标记售出不影响授权有效性。校验不占用新设备名额，可能每小时更新一次最近访问时间。

调用示例

将下面的 https://YOUR_WEBSITE_DOMAIN 替换为部署域名：

curl 'https://YOUR_WEBSITE_DOMAIN/api/cards/check' \
  -H 'Content-Type: application/json' \
  --data '{"code":"YOUR_CARD_CODE"}'
async function verifyLicense(baseUrl, license) {
  const response = await fetch(`${baseUrl}/api/verify`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ license })
  });
  if (!response.ok) throw new Error(`授权服务请求失败：HTTP ${response.status}`);
  const result = await response.json();
  if (result.ok !== true) throw new Error(result.reason || '授权无效');
  return result;
}

正常业务失败使用 HTTP 200。非法 JSON / 参数返回 400，不支持的格式返回 415，过大请求返回 413，频率超限返回 429。每个来源 IP 的三个公开接口合计限额为每分钟 120 次；429 可读取 Retry-After 后重试。

网络或服务错误应与卡密无效分别处理。卡密和 Token 是凭证，请通过 HTTPS 传输并妥善保存，勿放入 URL、日志或公开页面。
